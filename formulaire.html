Formulaire complet

Toutes les formules de la Partie A avec leurs unités. Tape un mot (« gauss », « capacité », « coax », « énergie »…) pour filtrer.

Constantes & outils (Ch. 0)

Constantes
$e=1{,}602\times10^{-19}$ C ; $\varepsilon_0=8{,}854\times10^{-12}$ F/m ; $\frac1{4\pi\varepsilon_0}\approx9\times10^9$ SI ; $\mu_0=4\pi\times10^{-7}$ H/m ; $c=1/\sqrt{\varepsilon_0\mu_0}\approx3\times10^8$ m/s
Produit scalaire
$\vec u\cdot\vec v=\|u\|\|v\|\cos\theta=u_xv_x+u_yv_y+u_zv_z$
Produit vectoriel
$\vec u\wedge\vec v=(u_yv_z-u_zv_y,\ u_zv_x-u_xv_z,\ u_xv_y-u_yv_x)$, $\|\vec u\wedge\vec v\|=\|u\|\|v\|\sin\theta$
Cylindriquesfil, coax, solénoïde
$\mathrm d\vec\ell=\mathrm dr\,\vec e_r+r\,\mathrm d\theta\,\vec e_\theta+\mathrm dz\,\vec e_z$ ; $\mathrm dV=r\,\mathrm dr\,\mathrm d\theta\,\mathrm dz$ ; aire latérale $2\pi rh$
Sphériquescharge, sphère
$\mathrm d\vec\ell=\mathrm dr\,\vec e_r+r\,\mathrm d\theta\,\vec e_\theta+r\sin\theta\,\mathrm d\varphi\,\vec e_\varphi$ ; $\mathrm dV=r^2\sin\theta\,\mathrm dr\,\mathrm d\theta\,\mathrm d\varphi$ ; aire $4\pi r^2$ ; coquille $4\pi r^2\mathrm dr$
1er ordre
$f(x+\mathrm dx)\simeq f(x)+f'(x)\,\mathrm dx$
Gradient
$\vec\nabla f=(\partial_xf,\partial_yf,\partial_zf)$ ; $\mathrm df=\vec\nabla f\cdot\mathrm d\vec\ell$ ; ⟂ aux surfaces de niveau
Divergence
$\mathrm{div}\vec A=\partial_xA_x+\partial_yA_y+\partial_zA_z$ (flux sortant par unité de volume)
Rotationnel
$\overrightarrow{\mathrm{rot}}\vec A=(\partial_yA_z-\partial_zA_y,\ \partial_zA_x-\partial_xA_z,\ \partial_xA_y-\partial_yA_x)$
Ostrogradski
$\oiint_S\vec A\cdot\mathrm d\vec S=\iiint_V\mathrm{div}\vec A\,\mathrm dV$
Stokes
$\oint_\Gamma\vec A\cdot\mathrm d\vec\ell=\iint_S\overrightarrow{\mathrm{rot}}\vec A\cdot\mathrm d\vec S$

Électrostatique (Ch. 1)

Densités
$\mathrm dq=\lambda\,\mathrm d\ell$ (C/m) $=\sigma\,\mathrm dS$ (C/m²) $=\rho\,\mathrm dV$ (C/m³)
Loi de Coulomb
$\vec F_{1\to2}=\frac{1}{4\pi\varepsilon_0}\frac{q_1q_2}{r^2}\vec u_{1\to2}$
Champ d'une charge
$\vec E=\frac{1}{4\pi\varepsilon_0}\frac{q}{r^2}\vec e_r$ (V/m) ; $\vec F=q'\vec E$
Superposition
$\vec E(M)=\int\frac{1}{4\pi\varepsilon_0}\frac{\mathrm dq}{PM^2}\vec u_{P\to M}$ ; $V(M)=\int\frac{1}{4\pi\varepsilon_0}\frac{\mathrm dq}{PM}$
Anneau (sur l'axe)
$E(z)=\frac{1}{4\pi\varepsilon_0}\frac{Qz}{(R^2+z^2)^{3/2}}$ ; $V(z)=\frac{1}{4\pi\varepsilon_0}\frac{Q}{\sqrt{R^2+z^2}}$
Potentiel
$\vec E=-\vec\nabla V$ ; $\mathrm dV=-\vec E\cdot\mathrm d\vec\ell$ ; $\int_A^B\vec E\cdot\mathrm d\vec\ell=V_A-V_B$ ; charge : $V=\frac{q}{4\pi\varepsilon_0r}$
Énergie, tension
$W_{A\to B}=q(V_A-V_B)$ ; $E_p=qV$ ; $1\ \mathrm{eV}=1{,}602\times10^{-19}$ J
Théorème de Gauss
$\oiint\vec E\cdot\mathrm d\vec S=\frac{Q_{int}}{\varepsilon_0}$ ⟺ $\mathrm{div}\vec E=\frac{\rho}{\varepsilon_0}$
Fil infini λ
$E=\frac{\lambda}{2\pi\varepsilon_0r}$
Plan infini σ
$E=\frac{\sigma}{2\varepsilon_0}$ (de chaque côté, sens opposés) ; 2 plans ±σ : $\frac{\sigma}{\varepsilon_0}$ entre, 0 dehors
Boule uniforme ρ
$E=\frac{\rho r}{3\varepsilon_0}$ ($r\lt R$) ; $E=\frac{Q}{4\pi\varepsilon_0r^2}$ ($r>R$) ; $V=\frac{\rho(3R^2-r^2)}{6\varepsilon_0}$ dedans, $\frac{\rho R^3}{3\varepsilon_0r}$ dehors
Statique
$\overrightarrow{\mathrm{rot}}\vec E=\vec0$ ; $\oint\vec E\cdot\mathrm d\vec\ell=0$
Densité d'énergie
$u_E=\frac12\varepsilon_0E^2$ (J/m³)

Conducteurs, condensateurs, courant (Ch. 2)

Conducteur à l'équilibre
$\vec E_{int}=\vec0$, $\rho_{int}=0$, $V$ = cste
Théorème de Coulomb
$\vec E=\frac{\sigma}{\varepsilon_0}\vec n$ (juste à l'extérieur)
Capacité
$Q=CU$ (F) ; $i=C\frac{\mathrm du}{\mathrm dt}$ ; $W=\frac12CU^2=\frac{Q^2}{2C}$
C plan
$C=\frac{\varepsilon_0S}{e}$ (isolant : $\varepsilon_0\to\varepsilon_r\varepsilon_0$)
C coaxial
$\frac C\ell=\frac{2\pi\varepsilon_0}{\ln(b/a)}$
C sphérique
$C=\frac{4\pi\varepsilon_0R_1R_2}{R_2-R_1}$ ; sphère seule $4\pi\varepsilon_0R$
Courant
$i=\frac{\mathrm dq}{\mathrm dt}$ ; $\vec j=nq\vec v_d$ (A/m²) ; $i=\iint\vec j\cdot\mathrm d\vec S$
Conservation
$\oiint\vec j\cdot\mathrm d\vec S=-\frac{\mathrm dQ_{int}}{\mathrm dt}$ ; $\mathrm{div}\vec j+\partial_t\rho=0$
Ohm local / Drude
$\vec j=\sigma\vec E$ ; $\sigma=\frac{ne^2\tau}{m}$ ; $\rho_r=1/\sigma$
Résistance
$U=Ri$ ; $R=\frac{\rho_rL}{S}$ ; $P=Ui$ ; Joule $Ri^2$
Couronne fendue (TD2)
$R=\frac{2\pi\rho}{e\ln(R_2/R_1)}$

Magnétostatique (Ch. 3)

Lorentz
$\vec F=q(\vec E+\vec v\wedge\vec B)$ ; force magnétique : travail nul
Laplace
$\mathrm d\vec F=i\,\mathrm d\vec\ell\wedge\vec B$ ; $F=i\ell B\sin\alpha$
Rayon de Larmor
$R=\frac{mv}{|q|B}$ ; $T=\frac{2\pi m}{|q|B}$
Moment magnétique
$\vec m=iS\vec n$ (A·m²) ; couple $\vec m\wedge\vec B$
Maxwell-flux
$\oiint\vec B\cdot\mathrm d\vec S=0$ ⟺ $\mathrm{div}\vec B=0$
Ampère (statique)
$\oint\vec B\cdot\mathrm d\vec\ell=\mu_0i_{enl}$ ⟺ $\overrightarrow{\mathrm{rot}}\vec B=\mu_0\vec j$
B fil infini
$B=\frac{\mu_0i}{2\pi r}$, orthoradial
B solénoïde
$B=\mu_0ni$ dedans (uniforme, axial), 0 dehors
B coaxial
$\frac{\mu_0i}{2\pi r}$ entre a et b ; 0 dehors
Inductance
$\Phi=Li$ (H)
L solénoïde
$L=\mu_0n^2\ell S=\frac{\mu_0N^2S}{\ell}$
L coaxial
$\frac L\ell=\frac{\mu_0}{2\pi}\ln\frac ba$ ; $\frac L\ell\cdot\frac C\ell=\varepsilon_0\mu_0=\frac1{c^2}$
Symétries
Plan de sym. : $\vec E$ contenu, $\vec B$ ⟂. Plan d'antisym. : $\vec E$ ⟂, $\vec B$ contenu.

Induction (Ch. 4)

Flux
$\Phi=\iint\vec B\cdot\vec n\,\mathrm dS$ (Wb = T·m²)
Faraday
$e=-\frac{\mathrm d\Phi}{\mathrm dt}$ ; $i=\frac eR$
Circuit mobile
$e=\oint(\vec v\wedge\vec B)\cdot\mathrm d\vec\ell$
Maxwell-Faraday
$\oint\vec E\cdot\mathrm d\vec\ell=-\frac{\mathrm d\Phi_B}{\mathrm dt}$ ⟺ $\overrightarrow{\mathrm{rot}}\vec E=-\frac{\partial\vec B}{\partial t}$
Rails de Laplace
$e=-B\ell v$ ; $i=\frac{B\ell v}{R}$ ; $F=\frac{B^2\ell^2v}{R}$ ; $\tau=\frac{mR}{B^2\ell^2}$
Auto-induction
$e=-L\frac{\mathrm di}{\mathrm dt}$ ; $u_L=L\frac{\mathrm di}{\mathrm dt}$ ; $W=\frac12Li^2$
Mutuelle
$\Phi_2=Mi_1$ ; $e_2=-M\frac{\mathrm di_1}{\mathrm dt}$
Densité d'énergie
$u_B=\frac{B^2}{2\mu_0}$
Oscillateur LC
$\ddot q+\frac{q}{LC}=0$ ; $\omega_0=\frac1{\sqrt{LC}}$

Maxwell & propagation (Ch. 5)

Courant de déplacement
$i_D=\varepsilon_0\frac{\mathrm d\Phi_E}{\mathrm dt}$
Maxwell-Ampère
$\oint\vec B\cdot\mathrm d\vec\ell=\mu_0i+\mu_0\varepsilon_0\frac{\mathrm d\Phi_E}{\mathrm dt}$ ⟺ $\overrightarrow{\mathrm{rot}}\vec B=\mu_0\vec j+\mu_0\varepsilon_0\frac{\partial\vec E}{\partial t}$
Les 4 équations
$\mathrm{div}\vec E=\frac\rho{\varepsilon_0}$ ; $\mathrm{div}\vec B=0$ ; $\overrightarrow{\mathrm{rot}}\vec E=-\partial_t\vec B$ ; $\overrightarrow{\mathrm{rot}}\vec B=\mu_0\vec j+\mu_0\varepsilon_0\partial_t\vec E$
Ligne LC
$\partial_zV=-\mathcal L\partial_tI$ ; $\partial_zI=-\mathcal C\partial_tV$ ; $v=\frac{1}{\sqrt{\mathcal{LC}}}$
D'Alembert
$\frac{\partial^2f}{\partial z^2}=\frac1{v^2}\frac{\partial^2f}{\partial t^2}$
Onde plane (vide)
$\partial_zE=-\partial_tB$ ; $\partial_zB=-\varepsilon_0\mu_0\partial_tE$ ; $c=\frac{1}{\sqrt{\varepsilon_0\mu_0}}$ ; $E/B=c$

TD 2 — câble à fuite

Isolant (tranche dx)
$R_f=\frac{\rho\ln(R_2/R_1)}{2\pi\,\mathrm dx}$
Équations
$V_1'=-\rho_1i$ ; $V_2'=\rho_2i$ ; $i'=-\frac{2\pi}{\rho\ln(R_2/R_1)}(V_1-V_2)$ ; $U=U_0e^{-x/\delta}$, $\delta=\sqrt{\frac{\rho\ln(R_2/R_1)}{2\pi(\rho_1+\rho_2)}}$
