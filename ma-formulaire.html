Ch. 1 — Complexes

Module, argument
$|z|=\sqrt{a^2+b^2}$ ; $\cos\theta=\frac a{|z|}$, $\sin\theta=\frac b{|z|}$
Conjugué
$\bar z=a-ib$ ; $z\bar z=|z|^2$ ; $z+\bar z=2\mathrm{Re}z$
Formes
$z=a+ib=r(\cos\theta+i\sin\theta)=re^{i\theta}$
Produit, quotient
$|zz'|=|z||z'|$, $\arg zz'=\arg z+\arg z'$ ; quotient : − des arguments
Euler
$\cos\theta=\frac{e^{i\theta}+e^{-i\theta}}2$, $\sin\theta=\frac{e^{i\theta}-e^{-i\theta}}{2i}$
De Moivre
$(\cos\theta+i\sin\theta)^n=\cos n\theta+i\sin n\theta$
Racines carrées de X + iY
$a^2-b^2=X$, $2ab=Y$, $a^2+b^2=\sqrt{X^2+Y^2}$
2ᵈ degré
$z=\frac{-b\pm\delta}{2a}$, $\delta^2=\Delta=b^2-4ac$
Racines n-ièmes
$z^n=Re^{i\alpha}$ ⇒ $z_k=R^{1/n}e^{i\frac{\alpha+2k\pi}n}$

Ch. 2 — Intégrales

Théorème fondamental
$\int_a^bf=F(b)-F(a)$, $F'=f$
IPP
$\int_a^buv'=[uv]_a^b-\int_a^bu'v$
Changement de variable
$t=\varphi(u)$ : $\int_a^bf(t)\mathrm dt=\int_{\varphi^{-1}(a)}^{\varphi^{-1}(b)}f(\varphi(u))\varphi'(u)\mathrm du$
$x^n$, $1/x$
$\frac{x^{n+1}}{n+1}$ ; $\ln|x|$
exp, cos, sin
$\frac{e^{ax}}a$ ; $\frac{\sin ax}a$ ; $-\frac{\cos ax}a$
arctan, arcsin
$\int\frac1{1+x^2}=\arctan x$ ; $\int\frac1{\sqrt{1-x^2}}=\arcsin x$
Formes composées
$u'u^n\to\frac{u^{n+1}}{n+1}$ ; $\frac{u'}u\to\ln|u|$ ; $u'e^u\to e^u$
Éléments simples
$\frac1{x-a}\to\ln|x-a|$ ; $\frac1{(x-a)^k}\to\frac{-1}{(k-1)(x-a)^{k-1}}$
Parité
impaire : $\int_{-a}^a=0$ ; paire : $2\int_0^a$

Ch. 4 — Intégrales multiples

Fubini
$\iint_Df=\int_a^b\int_{\varphi_1(x)}^{\varphi_2(x)}f\,\mathrm dy\,\mathrm dx$
Polaires
$x=r\cos\theta$, $y=r\sin\theta$, $\mathrm dx\mathrm dy=r\,\mathrm dr\,\mathrm d\theta$
Cylindriques
$\mathrm dV=r\,\mathrm dr\,\mathrm d\theta\,\mathrm dz$
Sphériques (latitude φ)
$x=r\cos\varphi\cos\theta$, $y=r\cos\varphi\sin\theta$, $z=r\sin\varphi$, $\mathrm dV=r^2\cos\varphi\,\mathrm dr\,\mathrm d\theta\,\mathrm d\varphi$
Masse, centre
$m=\iiint\rho$, $x_G=\frac1m\iiint x\rho$
Moment d'inertie
$J_\Delta=\iiint d^2\rho\,\mathrm dV$

Ch. 5 — Matrices

Produit
$(AB)_{ij}=\sum_ka_{ik}b_{kj}$ ; (n×p)(p×m) = n×m
Transposée
$(AB)^T=B^TA^T$
det 2×2
$ad-bc$
det n×n
$\sum_j(-1)^{i+j}a_{ij}\Delta_{ij}$
Propriétés
$\det AB=\det A\det B$ ; échange ⇒ signe ; $L_i+\lambda L_j$ ⇒ inchangé
Inverse 2×2
$\frac1{ad-bc}\begin{pmatrix}d&-b\\-c&a\end{pmatrix}$
Inverse
$A^{-1}=\frac1{\det A}{}^t\mathrm{com}A$ ; $(AB)^{-1}=B^{-1}A^{-1}$
Cramer
$x_i=\frac{\det A_i}{\det A}$

Ch. 6 — Séries de Fourier

Coefficients
$a_0=\frac1T\int_Tf$, $a_n=\frac2T\int_Tf\cos n\omega t$, $b_n=\frac2T\int_Tf\sin n\omega t$
Complexes
$c_n=\frac1T\int_Tfe^{-in\omega t}$, $c_n=\frac{a_n-ib_n}2$
Dirichlet
somme $=\frac{f(t^+)+f(t^-)}2$
Parseval
$\frac1T\int_Tf^2=a_0^2+\frac12\sum(a_n^2+b_n^2)=\sum|c_n|^2$
Spectre
$A_n=\sqrt{a_n^2+b_n^2}=2|c_n|$
Sommes
$\sum\frac1{n^2}=\frac{\pi^2}6$, $\sum\frac1{(2p+1)^2}=\frac{\pi^2}8$, $\sum\frac1{n^4}=\frac{\pi^4}{90}$

Ch. 7 — Intégrales généralisées & TF

Riemann
$\int_1^\infty t^{-\alpha}$ : α > 1 ; $\int_0^1t^{-\alpha}$ : α < 1
TF
$\hat f(\lambda)=\int f(t)e^{-2i\pi\lambda t}\mathrm dt$
Inversion
$f(t)=\int\hat f(\lambda)e^{2i\pi\lambda t}\mathrm d\lambda$
Porte
$\Pi\to\frac{\sin\pi\lambda}{\pi\lambda}$
Exponentielles
$e^{-a|t|}\to\frac{2a}{a^2+4\pi^2\lambda^2}$ ; $e^{-at}U\to\frac1{a+2i\pi\lambda}$
Propriétés
$f(t-a)\to e^{-2i\pi\lambda a}\hat f$ ; $f(at)\to\frac1{|a|}\hat f(\frac\lambda a)$ ; $f'\to2i\pi\lambda\hat f$
Plancherel
$\int|f|^2=\int|\hat f|^2$

Ch. 8 — Laplace

Définition
$F(p)=\int_0^\infty f(t)e^{-pt}\mathrm dt$
Dictionnaire
$1\to\frac1p$ ; $t^n\to\frac{n!}{p^{n+1}}$ ; $e^{at}\to\frac1{p-a}$
cos, sin
$\cos\omega t\to\frac p{p^2+\omega^2}$ ; $\sin\omega t\to\frac\omega{p^2+\omega^2}$
ch, sh
$\frac p{p^2-\omega^2}$ ; $\frac\omega{p^2-\omega^2}$
×e^{at}
$F(p-a)$
Retard
$f(t-a)U(t-a)\to e^{-ap}F(p)$ ; $U(t-a)\to\frac{e^{-ap}}p$
Dérivées
$f'\to pF-f(0)$ ; $f''\to p^2F-pf(0)-f'(0)$
Intégrale, convolution
$\int_0^tf\to\frac Fp$ ; $f*g\to FG$ ; $tf\to-F'$
