Électronique · Mémo

Formulaire complet

Tape un mot (« thévenin », « rc », « bode », « impédance »…) pour filtrer.

Ch. 1 — Notions de base

Courant
$I=\Delta Q/\Delta t$ (A), sens inverse des électrons
Tension
$U_{AB}=V_A-V_B$, flèche de B vers A
Loi d'Ohm
$U=RI$ (convention récepteur)
Puissance
$p=ui$ ; $P=UI$ ; résistance $P=RI^2=U^2/R$
Associations R
Série $R_1+R_2$ ; parallèle $\frac{R_1R_2}{R_1+R_2}$
Kirchhoff
Nœuds : $\sum I_{entrants}=\sum I_{sortants}$ ; mailles : $\sum U=0$
Diviseur de tension
$U_2=E\frac{R_2}{R_1+R_2}$
Diviseur de courant
$I_2=I\frac{R_1}{R_1+R_2}$
Thévenin / Norton
$E_{th}$ = tension à vide ; $I_N$ = courant de court-circuit ; $R_{th}=R_N$ (sources éteintes) ; $E_{th}=R_{th}I_N$
Source réelle
$V=E-RI$ (Thévenin) ⟺ $I=I_N-V/R$ (Norton)
Millman
$U=\dfrac{\sum E_k/R_k+\sum I_k}{\sum 1/R_k}$
Superposition
Somme des contributions de chaque source seule (tension → fil, courant → ouvert)
Pont de Wheatstone
Équilibre ⇔ $R_1R_3=R_2R_4$

Ch. 2 — Régime transitoire

Condensateur
$q=Cu$, $i=C\frac{\mathrm du}{\mathrm dt}$, $u_C$ continue, $E=\frac12Cu^2$
Bobine
$u=L\frac{\mathrm di}{\mathrm dt}$, $i_L$ continu, $E=\frac12Li^2$
Associations
C : parallèle $\sum C$, série $\frac1{C}=\sum\frac1{C_k}$ ; L : comme R
Permanent continu
C = circuit ouvert ; L = fil
τ
RC : $\tau=RC$ ; RL : $\tau=L/R$
1ᵉʳ ordre
$\tau\dot y+y=y_\infty$ ⇒ $y=y_\infty+(y(0^+)-y_\infty)e^{-t/\tau}$
Charge RC
$u_C=E(1-e^{-t/\tau})$, $i=\frac ERe^{-t/\tau}$
Décharge RC
$u_C=Ee^{-t/\tau}$, $i=-\frac ERe^{-t/\tau}$
Établissement RL
$i=\frac ER(1-e^{-t/\tau})$, $u_L=Ee^{-t/\tau}$
Repères
τ : 63 % ; 3τ : 95 % ; 5τ : 99 %
RLC série
$LC\ddot u_C+RC\dot u_C+u_C=e$ ; $\omega_0=\frac1{\sqrt{LC}}$, $\lambda=\frac R{2L}$, $Q=\frac1R\sqrt{\frac LC}$
RLC parallèle
$\ddot u+\frac1{RC}\dot u+\frac1{LC}u=0$ ; $Q=R\sqrt{\frac CL}$
Régimes
$r^2+2\lambda r+\omega_0^2=0$ ; Q < ½ apériodique, Q = ½ critique, Q > ½ pseudo-périodique, $\omega=\sqrt{\omega_0^2-\lambda^2}$
Pseudo-périodique (décharge)
$u_C=E\left(\cos\omega t+\frac\lambda\omega\sin\omega t\right)e^{-\lambda t}$
Critique
$u_C=E(1+\lambda t)e^{-\lambda t}$

Ch. 3 — Sinusoïdal & filtrage

Signal
$V_m\cos(\omega t+\phi)+V_{DC}$, $\omega=2\pi f$, $T=1/f$, $V_{cc}=2V_m$
Valeur efficace
$V_{eff}=V_m/\sqrt2$
Déphasage
$\Delta\phi=2\pi\,d/T$
Complexes
$|a+jb|=\sqrt{a^2+b^2}$ ; $\arg\frac{z_1}{z_2}=\arg z_1-\arg z_2$
Aller-retour
$\underline X=X_me^{j\phi}$ ; $x(t)=|\underline X|\cos(\omega t+\arg\underline X)$
Dériver / intégrer
× $j\omega$ / ÷ $j\omega$
Impédances
$Z_R=R$, $Z_L=jL\omega$, $Z_C=\frac1{jC\omega}$
Transfert
$\underline H=\frac{\underline V_s}{\underline V_e}$, $G=|\underline H|$, $\phi=\arg\underline H$
Décibels
$G_{dB}=20\log G$ ; −3 dB ⇔ $G_{max}/\sqrt2$
Passe-bas 1ᵉʳ ordre
$\frac{1}{1+jx}$, $x=RC\omega$ : 0 puis −20 dB/déc, −45° à x=1
Passe-haut 1ᵉʳ ordre
$\frac{jx}{1+jx}$ : +20 dB/déc puis 0, +45° à x=1
Passe-bande 2ᵈ ordre
$\frac{H_0}{1+jQ(x-1/x)}$ ; bande passante $\Delta x=1/Q$
Pont de Wien
$\frac{1/3}{1+\frac j3(x-\frac1x)}$, coupures 0,30 et 3,30
R + (L ∥ C)
$\frac{1}{1+jR(C\omega-\frac1{L\omega})}$, $Q=R\sqrt{C/L}$
Créneau ±U
$\frac{4U}{\pi}\left(\sin\omega t+\frac{\sin3\omega t}3+\frac{\sin5\omega t}5+\dots\right)$
