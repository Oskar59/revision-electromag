Patterns : quand on te demande X, tu fais Y

Une douzaine de types de questions couvrent tout le programme. Pour chacun : le déclencheur, la méthode, le piège.

ACircuits en continu (Ch. 1)

Tension d'une R parmi plusieurs R parcourues par le même courant
→
Diviseur de tension $U_k=E\frac{R_k}{\sum R}$ (regrouper les parallèles avant ; rien ne doit sortir au milieu).
Courant dans une branche parmi deux en parallèle
→
Diviseur de courant $I_2=I\frac{R_1}{R_1+R_2}$ (l'autre R au numérateur).
Tension d'un nœud où arrivent plusieurs branches
→
Millman $U=\frac{\sum E_k/R_k+\sum I_k}{\sum1/R_k}$.
« Par superposition » / plusieurs sources
→
Une source à la fois : tension → fil, courant → ouvert. Somme des contributions.
« Montrer que AB est équivalent à un générateur »
→
Norton pour chaque branche (E,R) ⇒ courants s'ajoutent, R en parallèle ⇒ reconvertir en Thévenin.
« Générateur de Thévenin vu par … »
→
Retirer l'élément : $E_{th}$ = tension à vide ; $R_{th}$ = résistance vue, sources éteintes.
Voltmètre idéal / pont
→
Aucun courant dans le voltmètre ⇒ deux diviseurs indépendants ; équilibre ⇔ produits en croix égaux.
Valeurs manquantes sur un schéma
→
Nœuds (courants) et mailles (tensions), en respectant les flèches.

BRégime transitoire (Ch. 2)

P1 — « Déterminer u_C(t) / i(t) après la fermeture/ouverture »
  1. t = 0⁻ (« depuis très longtemps ») : C = ouvert, L = fil ⇒ $u_C(0^-)$, $i_L(0^-)$.
  2. t = 0⁺ : $u_C$ et $i_L$ continus (les autres peuvent sauter).
  3. EDO pour t > 0 (mailles/nœuds + Ohm + loi du composant), forme $\tau y'+y=y_\infty$.
  4. Solution $y=Ae^{-t/\tau}+y_\infty$, A par la condition initiale.
  5. Déduire les autres grandeurs ($i=C\dot u$, $u_L=L\dot i$, Ohm).

Raccourci : $y(t)=y_\infty+(y(0^+)-y_\infty)e^{-t/\tau}$ ; τ = RC ou L/R (R vue par C ou L, sources éteintes).

P2 — « Circuit compliqué + un seul C (ou L) »

Thévenin vu par C ⇒ circuit RC simple : $\tau=R_{th}C$, $u_\infty=E_{th}$.

P3 — « Énergie perdue / dissipée »

Énergie initiale stockée $\frac12Cu^2$ ou $\frac12Li^2$ ; énergie Joule $\int_0^\infty Ri^2\,\mathrm dt$ (avec $\int_0^\infty e^{-2t/\tau}\mathrm dt=\tau/2$). Elles sont égales en l'absence de source.

P4 — « Au bout de combien de temps … x % »

$e^{-t/\tau}=\frac{x}{100}$ ⇒ $t=\tau\ln\frac{100}x$. (1 % ⇒ 4,6τ ; 0,01 % ⇒ 9,2τ.) Amplitude d'oscillation divisée par N ⇒ $t=\frac{\ln N}\lambda$.

P5 — « RLC »
  1. EDO : série → mailles ; parallèle → nœuds puis dériver.
  2. Forme $\ddot y+2\lambda\dot y+\omega_0^2y=0$ (ou $\frac{\omega_0}Q\dot y$).
  3. Série : $\lambda=\frac R{2L}$, $Q=\frac1R\sqrt{\frac LC}$ ; parallèle : $\lambda=\frac1{2RC}$, $Q=R\sqrt{\frac CL}$.
  4. Régime selon Q vs 1/2.
  5. Pseudo-périodique : $e^{-\lambda t}(A\cos\omega t+B\sin\omega t)$, $\omega=\sqrt{\omega_0^2-\lambda^2}$ ; A et B avec deux conditions initiales ($y(0)$ et $\dot y(0)$ via le courant).

CRégime sinusoïdal & filtres (Ch. 3)

Oscillogramme
→
T, $V_m$, $V_{eff}=V_m/\sqrt2$, $\Delta\phi=2\pi t_1/T$ (en avance = pic en premier).
« Déterminer u(t) » avec une source sinusoïdale
→
Complexes : impédances ⇒ diviseur/Millman ⇒ $|\underline U|$ et $\arg\underline U$ ⇒ $u(t)=|\underline U|\cos(\omega t+\arg\underline U)$.
Sources à fréquences différentes
→
Superposition, une fréquence à la fois, somme en temporel.
« Nature du filtre »
→
BF : L fil, C ouvert ; HF : L ouvert, C fil ⇒ que vaut $v_s$ ?
« Fonction de transfert »
→
Diviseur en sortie ouverte ⇒ forme canonique (1 + … au dénominateur, $x=\omega/\omega_0$) ⇒ $H_0$, ω₀, Q, ordre.
« Diagramme de Bode asymptotique »
→
Terme dominant pour x ≪ 1 et x ≫ 1 ⇒ pentes (±20n dB/déc) et phases limites ; point x = 1.
« Pulsations de coupure »
→
$G=G_{max}/\sqrt2$ ⇔ partie imaginaire du dénominateur (normalisé) = ±1.
« Expression approchée pour f = … »
→
Calculer x ; si x ≪ 1 ou ≫ 1, approximation ; sinon calcul exact.
Créneau en entrée
→
Harmoniques impairs ; zone en $1/(jx)$ ⇒ intégrateur (triangle) ; zone en $jx$ ⇒ dérivateur (pics) ; passe-bande sélectif ⇒ sinusoïde.
« Charge branchée en sortie »
→
L'impédance de sortie change ⇒ H change : recalculer avec $Z\parallel R_L$.

DCheck-list avant de rendre

Les vérifications qui rattrapent les erreurs
  1. Homogénéité : RC, L/R en secondes ; LC en s² ; RCω, Lω/R sans unité.
  2. Cas limites : R → 0, R → ∞, ω → 0, ω → ∞, t → ∞ redonnent-ils l'évidence ?
  3. Continuité de $u_C$ et $i_L$ à t = 0 respectée par ta solution ?
  4. Valeur finale = régime permanent (C ouvert, L fil) ?
  5. Sens : un résultat négatif est-il cohérent avec la convention choisie ?
  6. Gain max d'un filtre passif ≤ 1 (0 dB) ; phase dans le bon intervalle.
